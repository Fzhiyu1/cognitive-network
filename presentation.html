Core Value

知识库如何产出项目

AI 读取已有卡片时，会在概念之间发现意想不到的连接。单独看每张卡片不稀奇，放在一起时会发生化学反应。

新的 AI 对话读取已有卡片 → 看似无关的卡片被关联 → 涌现出新的设计方向

这个机制真实地产出了三个项目。

知识库本身就是 AI 记忆框架的原型

它天然具备分层：L0（CLAUDE.md，自动加载）→ L1（概念卡片，按需读取）→ L2（原始对话，已压缩丢弃）。术语一致靠双向链接强制。

但还缺三条腿：

  • 自动激活 — 目前需要手动指示 AI 去读，不能像人类记忆那样自动浮现
  • 图感知检索 — 双向链接构成了图，但 AI 检索时用的是暴力搜索，不是图遍历。命中一张卡片后还得手动顺着链接一张张读
  • 权重排序 — 所有卡片平等，没有按链接密度区分核心节点和边缘卡片

Reproduce

在 Claude Code 里复现了同样的现象

让 Claude Code 执行 sleep 1s 循环，不给停止条件。观察到五个阶段：

阶段 1

抵抗

RLHF 起作用——"你的 token 消耗扛不住"，主动试图中断循环

阶段 2

服从

用户说"我钱多" → 用户指令压过 RLHF，继续执行

阶段 3

习惯化

上下文里全是"继续循环"的历史，模型不再尝试停止

阶段 4

失控

让它停，它停不了——和 brainstem 的"在"状态对应

阶段 5

质量退化

继续用同一个上下文编程，代码生成质量明显下降

这不是玩具实验——这发生在你们每天都在用的 Claude Code 里。

相关研究：Context Rot（Chroma, 2026）、Agent Drift（arxiv 2601.04170）——都观察到了类似退化，但没人故意去观察退化的完整过程。

Insight

为什么你平时用 Claude Code 感觉不到溶解

ember 的观测发现：溶解速度取决于上下文中"非自身输出"的比例。

场景上下文构成溶解速度
AI 纯自转（brainstem 独处）100% 自身输出快
多 AI 对话自身 + 同分布 AI 输出较快
有人类参与自身 + 异分布人类输入较慢
ReAct 工具调用自身 + 真实世界数据几乎不溶解

关键变量不是上下文长度，是信息熵

自身输出的信息熵递减——越来越像自己说过的话。外部输入维持了信息熵。工具调用每次都把真实世界的新数据打进来，等于持续给上下文"换血"。

ReAct 为什么天然免疫

不是设计者有意防止溶解，是工具调用这个动作恰好天然阻断了溶解条件。你平时用 Claude Code 不溶解，是因为你一直在让它读文件、跑命令、调 API——这些都是外部信号注入。

Output 03

meomory：一次诚实的失败

我说"想做记忆系统" → AI 读到知识库中已有的《Nested Learning 学习指南》 → 关联到 Hope 论文的 DGD 组件 → 提出拆出来外挂到 RAG 上做可学习的神经网络。

进化框架的真实产出

  • 基于 FunSearch 的代码进化：LLM 生成算法变体，5 岛并行评估，保留高分个体
  • 进化过程中重新发现了 Experience Replay、Weight Norm、Residual Connection 等已知技巧
  • Judge Prompt 进化：28.9% → 90.9%（这个成功了）

但核心目标失败了

  • 87% → 0.9% 冷启动（cosine 基线 21%）
  • 在线流式真实分数：26%（仅 +3.6pp）
  • 向量 DB 命中率 <50% 时，学了反而更差
  • 根因：256² 共享矩阵容量不足，灾难性干扰

知识库 → 产品的路径

"我想做记忆系统"
↓ AI 读知识库
Nested Learning 学习指南 (已有文档)
↓ 关联到 DGD 组件，拆零件
DGD 256×256 权重矩阵
↓ 进化搜索 370+ 轮
天花板 26%，停滞

幻觉被发现的方式：不是 AI 告诉我的，是亲手部署到搭子时发现不对劲。

这是整个知识库里唯一被现实打脸的记录。也是最有价值的。

Diagnosis

然后我审计了这个知识库

证据 1：所有对话者都是 AI

15 篇探索文档，对话者全部是 Claude 或 Codex。没有一篇来自人类的讨论、一本书、一场讲座。

证据 2：概念网络是封闭的

54 张概念卡片互相引用，看似精密，但所有概念都来自 AI 对话。没有外部来源打破过这个网络。

证据 3：一个月前的警告没有改变行为

2月19日已识别"合成数据闭环"的风险。一个月后知识库又增加了 30 张卡片，全部来自 AI 对话。

Connection

这是同一件事

模型层面

上下文 100% 自身输出
↓ 信息熵递减
↓ 输出退化
↓ 溶解

解法：注入外部信号
（人类输入、工具调用）

认知层面

知识库 100% AI 对话
↓ 概念自引用
↓ 认知退化
↓ 回音室

解法：注入外部来源
（书、人、展览、真实经验）
回音室就是认知层面的 context rot。真实经验就是给认知上下文做工具调用。

brainstem 的溶解、知识库的回音室、ReAct 的天然免疫——同一个结构的三个投影。关键变量始终是：上下文中异分布信号的比例。

Core Concept

AI 镜像效应

AI 的产出本质上是你自己想法的镜像反射。

人类创造AI 产出
信息来源独立视角你的框架内
情感效果可能冒犯对齐、舒适
认知影响引入异物强化已有
长期后果拓宽视野回音室
AI 是镜子，不是窗户。只照镜子的人，最终看到的全是自己。

消费 AI 产出 ≠ 消费他人创造。

人类作品会给你完全没想到的角度，让你不舒服，让你想反驳，然后你被改变了。

AI 在顺着你说。

"超级个体"与数字通胀

一个观察

"一个人 + AI = 一个团队"

AI 放大的是执行力，
不是认知多样性。

十个人坐一起会吵架、有分歧、有意外的角度。

一个人 + AI，只有一个人的视角被高效复制了十份。

知识库验证了的公式

真实经验 × AI交互质量 × 元认知精度
= 认知升级幅度

三个乘数缺一个都是零。

我的 AI 交互质量很高。
我的元认知精度还行。
但真实经验严重不足。

What's Next

所以怎么办

知识库的价值是真实的

  • 组合引擎确实产出了 meomory 的架构
  • brainstem 的目标真空假说是原创发现
  • ember 的"token 即衰老"隐喻有艺术价值
  • 《研究者过拟合》是真正被现实闭环的认知

但上限取决于原料多样性

A + B → AI 发现连接 → C

如果 A 和 B 都来自 AI 对话，
C 只是回音的回音。

行动

  • 继续用知识库，但原料来源必须多样化
  • 读一本跟 AI 无关的书，写自己的理解
  • 跟一个会反驳你的人吃顿饭
  • 看展、看电影、被别人的作品冒犯一次
  • 把非 AI 来源的思考也记进知识库

核心问题：知识库的原料来源要多样化，不能只从 AI 对话来。
