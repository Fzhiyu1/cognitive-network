# VCP 记忆系统

**领域**：LLM Agent 记忆 / 工程实现
**项目**：[VCPToolBox](https://github.com/lioensky/VCPToolBox)（1578⭐）
**关联概念**：[[记忆迁移]]、[[记忆写入]]、[[前意识激活层]]

## 概述

VCP 是一个完整的 AI Agent 记忆系统，走的是**图拓扑 + 脉冲传播**路线，和 meomory 的 **DGD 关联记忆**路线不同。两者不冲突，可以互补。

## 三个核心机制

### 1. AgentDream（睡眠巩固）

Agent 在空闲时自主"做梦"整理记忆：
- 触发：凌晨 1-6 点 + 8 小时冷却 + 60% 概率（三层门控）
- 选种子：自适应时间窗口（7→30→90→180 天），随机采样 1-5 篇
- 联想：embedding 向量检索（个人:公共 = 3:1），取 top-12 联想
- 操作：LLM 生成梦境叙事，提出 merge（合并）/ delete（删除）/ insight（感悟）建议
- 审批：所有操作 pending_review，人类确认后才执行
- 设计哲学：**AI 负责建议，人类保留决定权**

### 2. Tag 共现网络 + 脉冲传播

检索不靠直接相似度匹配，靠标签之间的**多跳传播**：
- 标签从日记的 `Tag:` 行自动提取，不需要手动定义
- 共现矩阵：同一文件中的标签对建立有向加权边，权重由位置决定（靠前的势能高）
- 检索时：种子标签激活 → 沿共现关系 2 跳扩散 → 衰减因子 0.3 → 涌现上限 50 个
- 能找到 embedding 空间中不相近但**拓扑上相连**的记忆

### 3. 写入管道

AI 在回复中直接标记要存的内容 → 自动提取 → 自动生成 tag → 文件监听 → 批处理分块 → embedding → 入库。全自动，不需要人说"记录一下"。

## 与 meomory 的对比

| | meomory (DGD) | VCP (脉冲传播) |
|--|---------------|---------------|
| 检索 | M × query → 线性变换，O(1) | 标签脉冲扩散，多跳 |
| 学习 | **从使用反馈在线学习** | 从共现统计学习（不从反馈学） |
| 巩固 | 概念层：压缩合并（规划中） | AgentDream：做梦整理（已实现） |
| 写入 | 手动触发（规划自动化） | AI 自标记 + 文件监听（已实现） |
| 理论 | 有认知科学理论体系支撑 | 纯工程直觉 |
| 验证 | benchmark 实验 | 用户使用反馈 |

## 可能的融合路径

两套系统不冲突，可以在不同层级叠加：

1. **写入用 VCP 的思路**：AI 自标记 + 自动 tag + 文件监听管道。解决"什么时候写"
2. **巩固用 AgentDream 的思路**：定时 + 概率 + 冷却的三层门控 + 人工审批。解决"怎么整理"
3. **检索用 meomory 的 DGD**：在 VCP 的图检索结果上叠加 DGD 排序。DGD 从反馈中学"哪些结果对这个用户真正有用"
4. **图拓扑 + DGD 结合**：VCP 的脉冲传播找候选（多跳联想），DGD 的 M 矩阵排序（使用经验）。候选用图找，排序用学习。

融合后的架构：
```
写入：AI 自标记 → 自动 tag → 入输入层
巩固：AgentDream 式定期压缩 → 输入层沉淀到概念层（记忆迁移）
检索：图脉冲传播（找候选）→ DGD M 矩阵（排序）→ 注入上下文
反馈：LLM Judge 观察 → DGD 更新 M
```
