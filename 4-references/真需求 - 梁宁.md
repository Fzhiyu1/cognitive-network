# 真需求 — 梁宁

**领域**：商业方法论 / 产品设计 / 组织模式
**作者**：梁宁
**PDF**：本目录 `真需求-梁宁.pdf`（890 页 calibre 转档）
**关联概念**：[[商业闭环三要素]]、[[产品价值三层]]、[[共识的四重分歧]]、[[产品场景匹配]]、[[应然与实然]]

## 全书骨架

四个 PART，十六章：

| PART | 章节 | 主线 |
|------|------|------|
| ONE 价值 | 1-5 | 功能价值 / 情绪价值 / 资产价值 / 价值组合创新 / 品牌 |
| TWO 共识 | 6-11 | 感知分歧 / 想象分歧 / 场景分歧 / 利益分歧 / 认知战 / 关系 |
| THREE 模式 | 12-14 | 能力系统 / 变现逻辑 / 分配机制 |
| FOUR 求真 | 15-16 | 应然与实然 / 第一性原理 |

闭环链路：洞察需求 → 提供价值 → 与市场达成共识 → 获得成交与关系 → 换来钱与资源 → 投资自己的竞争力 → 形成生存优势。

## 核心公式

书中给出的几个显式公式：

```
产品价值 = 功能价值 + 情绪价值 + 资产价值
情绪价值 = 生理唤起 + 认知标记 + 心理账户
品牌     = 一代代的产品 + 公共记忆 + 时间过滤
改变     : 不满情绪 × 愿景 × 第一步 > 改变的阻力（贝克哈德-哈里斯公式）
```

## 关键论断摘录

**关于价值**
- 商业价值由交易对手盘（买方）决定，不是自己一厢情愿说有就有
- 功能价值的实质是基础需求 + 效率需求，四个模型：原材料/劳动力、专利IP、平台/供应链、基础设施
- 情绪价值三个付费点：保障感（对抗担心）、愉悦感（对抗枯燥）、彰显性（对抗自卑）
- 资产价值的两个条件：有专门市场/二手市场；价格依赖某个共识
- 创新就是价值组合的重排——功能类产品不断整合，情绪类产品不断分化
- 唯有无形之物才能不朽，所以品牌能穿越时间而产品不能

**关于共识**
- 价值成立但市场不动，一定是感知、想象、场景、利益相关人四个环节至少一个卡顿
- 用户研究更重要的是研究用户为什么**不**行动
- 期望属性就是核心卖点，它的要求是必须确定性交付——承诺了不能确定交付，就是智商税
- 体验管理的核心是预期管理
- 用户画像 vs 用户人设：画像适合功能刚需品，供给过剩时代要看人设
- 没有产品场景匹配（PSF），就没有产品市场匹配（PMF）
- 一个人的利益就是他的态度
- 关系四次第：需要 → 喜欢 → 认同 → 归属；认同是忠诚的开始
- 《鬼谷子》十二篇 = 说服的十二步用户旅程图，核心字是"符"

**关于模式**
- 成熟市场里需求是公共的、供给是类似的，只有生存模式是自己的
- 传统企业收入 = 单价 × 销量；互联网企业收入 = 用户数 × ARPU
- 模式第一问：拿谁的钱
- 认知是因，创新是果；认知决定能力的顶，安全是底
- 企业竞争力来自人才生态，人才生态来自分配机制；分配权是权力的核心

**关于求真**
- 应然是脑中该有的样子，实然是实际的样子；创新者要在实然里看到应然，再把应然变成实然
- 李兴平（先实然后应然）vs 王小川（先应然后实然）：精英困境在于抽象框架会遮蔽现实的复杂性
- 第一性原理 = 回溯到品类开端，从根本存在价值和物理要素重构方案，而非同维模仿

## 主要案例

泡泡玛特盲盒（IP 撑资产价值）· 人造钻石（毁灭稀缺性即毁灭价值）· 无抗猪肉（有价值点但用户感受不到）· 农夫山泉天然水（砸对手的锅式认知战）· 脑白金（感知设计 + 信息包设计 + 节奏）· 腾讯 OICQ（网吧场景决定云端存储）· 瑞幸（网约车团队的四个能力系统迁移）· 星链（需求明确的超大市场用新模式入局）· 海底捞 vs 吉野家 vs 新荣记（强管理 vs 强激发的分配光谱）· hao123 vs 搜狗（草根与精英的两条路径）

## 与本知识库的关系

本库此前几乎全是 AI / 认知科学 / 工程方法论，这是第一本纯商业书。三个真实接口：

1. **"用户为什么不行动"与 [[失败可见性]]**：梁宁说产品调研的重点是研究不行动，本库说进化系统里失败样本比成功样本信息量大——同一种"负例才是信号"的取向。
2. **应然与实然 vs [[知道与推测不分]]**：精英创业者用抽象框架推导应然、把推导当已知，正是"知道与推测不分"在商业场景的实例。
3. **认知战 vs [[描述即污染]]**：认知战是主动构建对方的认知框架，而 [[描述即污染]] 说的是描述行为本身会改变被描述对象——认知战可以看作是把这一效应武器化。

另外"共识"这一整个 PART 讨论的是多主体如何对齐语义，与本库 [[判断力的有效梯度]] 讨论的"人给系统提供什么信号"结构相似：都是在问，一方脑中的判断如何变成另一方的行动。
