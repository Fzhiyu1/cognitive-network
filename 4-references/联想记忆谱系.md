# 联想记忆谱系

**领域**:AI / 认知科学 / 类脑计算
**关联概念**:[[关联记忆]]、[[记忆假肢]]

## 简介

一条从 1980s 延续至今的 AI 研究主线:**用"键值对 + 相似性检索"做智能,而非用"反向传播 + 深度神经网络"**。

这条线和深度学习主流平行发展,多次被冷藏又复兴。2020 年代正在经历第三次复兴(由 Modern Hopfield 和 Titans 引爆)。

## 完整时间线

### 1980s — 起点

**Hopfield Networks** (John Hopfield, 1982)
- 神经元网络存储"吸引子"模式
- 不完整输入 → 网络碰撞到最近的存储模式
- **核心思想**:联想记忆 = 高维空间里的能量最小点
- 限制:容量约 0.14N 个模式(N = 神经元数)

**Sparse Distributed Memory (SDM)** (Pentti Kanerva, 1988)
- ⭐ 联想记忆流派的"圣经级"工作
- 高维二进制向量作为地址(~1000 bits)
- 输入找距离近的多个地址,读/写叠加
- 海明距离 = 检索相似性
- **和 cogg 关系**:cogg ≈ 整数版 + K 维度版 SDM

### 1990s — 扩展

**Holographic Reduced Representations (HRR)** (Tony Plate, 1995)
- 用循环卷积做"绑定"(X ⊗ Y = 新向量)
- 解绑定:用反向操作
- 支持复杂结构表示(树、图等)

**Vector Symbolic Architectures (VSA)** (Kanerva 后续 + 多位学者)
- HRR 的泛化
- 用 XOR / 循环卷积 / 点积做绑定 + 叠加
- 能做类比推理 (A:B :: C:?)
- **和 cogg 关系**:cogg 的 XOR 锚点 = VSA binding 的极简实例

**FARG / Copycat / Tabletop** (Hofstadter 团队)
- Slipnet 激活网络做类比推理
- 认为**类比是认知的核心**
- 和主流 AI 的"统计学习"完全不同路数
- 参见 [[侯世达 - 怪圈与类比]]

### 2000s — 沉寂期

主流:SVM / 核方法 / 统计学习。联想记忆被冷藏。

Hofstadter 一派坚持"符号类比"方向,但很小众。

### 2010s — 火种复燃

**Neural Turing Machine (NTM)** (Graves et al., DeepMind, 2014)
- 神经网络 + 可微分外部记忆矩阵
- 网络学会读写这个矩阵(soft attention 定位)
- **联想记忆的"神经网络化"实现**

**Differentiable Neural Computer (DNC)** (Graves, 2016)
- NTM 升级版,加入更复杂的内存管理
- 能学习图遍历、复制、推理任务

**Memory Networks** (Weston et al., Facebook, 2014)
- 显式键值对记忆层
- 查询用注意力机制

### 2020s — 大复兴

**Modern Hopfield Networks** (Ramsauer et al., ICLR 2021)
- ⭐ **炸响复兴信号**
- 证明现代 Hopfield 网络容量是**指数级**的
- **证明 Transformer 的 attention 数学上就是 Hopfield**
- 重新评估了 Hopfield 网络的价值

**RETRO** (DeepMind, 2021)
- LLM + 显式检索数据库(trillion 级 token)
- 证明"小模型 + 大记忆"vs"大模型 + 小记忆",效果可比
- 联想记忆思路重返前沿

**kNN-LM** (Khandelwal et al., 2019)
- LLM 直接做最近邻检索
- 退化成"键值对查找"也能增强

**Hyperdimensional Computing (HDC) 复兴** (IBM 苏黎世等, 2024 多篇)
- 用超高维二进制向量 (~10000 bits)
- XOR 绑定 + 海明相似性
- **类脑硬件友好**(Loihi / SpiNNaker)
- 极快 + 极省能

**Mamba / State Space Models** (Albert Gu, Tri Dao, 2023-2024)
- 不是显式键值对,但维护**固定大小压缩状态**
- 状态根据输入流选择性更新
- Mamba-2 证明和 attention 某些形式数学等价

**Memory Layers** (Meta, 2024)
- 在 Transformer 中插入**显式键值对记忆层**
- 极大压缩参数(很多知识不需要训练,存就行)

**Test-Time Training / Titans** (Google, 2024 末)
- 推理时模型权重持续更新
- 长期记忆用梯度更新(测试时学习)
- **在测试时存储新关联** — 这就是"会学的 cogg"的神经网络版

### 2026 — cogg 加入队列

Harry 的 **cogg** (2025/12 起)
- 独立重新发明这条线
- 整数版 SDM + K 维度 + 回撞验证
- 走极端资源最小化
- 参见 [[Harry - cogg 设计者]]

## 这条谱系的家族树

```
Hopfield Networks (1982)
   │
   └── SDM (Kanerva 1988)
           │
           ├── HRR (Plate 1990s) ──── VSA/HDC ─────────┐
           │                                            │
           └── Slipnet (Hofstadter)                    │
                                                        │
   ┌── NTM/DNC (2014-2016)                             │
   │
   └── Memory Networks (2014)                          │
                                                        │
   ═══════════ 2020s 复兴 ═══════════                  │
                                                        │
   Modern Hopfield (2021)  ◄── "attention = Hopfield"  │
           │                                            │
   RETRO / kNN-LM ─── Memory Layers (2024)             │
           │                                            │
   Mamba / SSM ──── Titans (2024) ─────────────────────┘
           │
   cogg (Harry, 2026) ─── 独立重发明路径
```

## 共同信念(这条线的研究者都相信的)

1. **智能的核心不是统计学习,是联想匹配**
2. **记忆应该是架构的一等公民,不是神经网络的副产物**
3. **离散 / 稀疏 / 局部 表征有本质价值,不只是神经网络的近似**
4. **类脑硬件终将胜过 GPU**(长期)

## 主流 vs 这条谱系

| 维度 | 主流 (Transformer) | 联想记忆谱系 |
|------|-------------------|-----------|
| 表征 | 连续向量 | 离散/稀疏向量 |
| 学习 | 反向传播 | Hebbian / 进化 / 能量最小 |
| 记忆 | 权重里 | 显式结构 |
| 资源 | GPU 必须 | CPU / 类脑硬件 |
| 优势 | 性能 | 效率 / 可解释 / 在线学习 |

## 为什么现在值得关注

2020s 的三个趋势都推向这条线:

1. **能耗问题**:LLM 训练能耗 megawatts, 不可持续
2. **类脑硬件成熟**:Loihi 2 / SpiNNaker 2 / TrueNorth 等可用
3. **Modern Hopfield 发现**:数学上 attention = Hopfield → 这条线和主流并非对立

**"联想记忆"可能是下一代 AI 架构的基础**,即使它不完全替代 Transformer。
