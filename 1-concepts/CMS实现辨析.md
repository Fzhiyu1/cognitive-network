# CMS 实现辨析

**提出者**：fangzhiyu
**日期**：2026年3月16日
**来源**：meomory 参数搜索实验中的发现

## 定义

CMS（连续记忆系统）的多时间尺度分层应该靠**更新频率**区分，不是靠**α 衰减率**区分。meomory 项目中曾用 α 区分层级（0.9/0.99/0.999），实验证明这是错误的——α<1.0 导致性能崩塌。

## 错误的实现 vs 正确的实现

```
错误（meomory 曾用的）：
  高频层：α=0.9，每次都更新  → P@1 崩到 28.6%
  低频层：α=0.999，每次都更新
  → 用 α 模拟时间尺度 → 失败

正确（Hope 原论文）：
  高频层：α=1.0，每次查询都更新
  低频层：α=1.0，每 N 次查询更新一次
  → 用更新频率区分时间尺度 → 所有层 α=1.0
```

## 三个关键差异

| | Hope CMS（正确） | meomory 旧 CMS（错误） |
|--|-----------------|----------------------|
| 分层机制 | 更新频率不同 | α 不同 |
| 层间关系 | 串联（高频输出喂给低频） | 并联（各自独立加权合并） |
| α 值 | 所有层 α=1.0 | 各层不同（0.9/0.99/0.999） |

## 为什么 α 区分不工作

实验 A 数据：

| α | P@1 (BigBang) |
|---|---------------|
| 1.0 | 78.6% |
| 0.95 | 7.1%（死亡谷） |
| 0.9 | 28.6% |

α<1.0 时对角线指数衰减（0.95^280 ≈ 0），基础结构崩塌。但 α=1.0 时 DGD 仍有遗忘——通过 `−η·k·kᵀ` 项的干扰遗忘，不是时间衰减。所以 α 应该只取 1.0，多时间尺度靠其他方式实现。

## 单层 DGD 为什么就够了

单层 α=1.0 每次更新 = Hope CMS 的高频层。它本身就是正确的最简情况。加 CMS 用错了方法（α 区分），反而破坏了本来对的东西。

## 正确的 CMS 实现方向

如果未来要加多时间尺度：
1. 所有层 α=1.0（不衰减）
2. 高频层每次查询更新，低频层每 N 次更新
3. 层间串联而非并联
4. 或者直接在内容层做时间分层（[[记忆迁移]]），不在权重层做

## 关联概念

- [[记忆迁移]] — 内容层分层可能比权重层 CMS 更合适
- [[多层有损压缩]] — 遗忘靠压缩产生，不靠 α 衰减
- [[关联记忆]] — DGD 的干扰遗忘（η·k·kᵀ）已经提供了足够的遗忘机制
- [[默认值运气]] — α=1.0 碰巧是对的，CMS 的 α 值碰巧暴露了问题
- [[Hope记忆外挂]] — Hope 原论文的 CMS 用更新频率区分，不是 α
