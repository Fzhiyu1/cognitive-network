# 反馈累积阈值

**提出者**：fangzhiyu
**日期**：2026年3月16日
**来源**：meomory CMS 噪声过滤问题的讨论

## 定义

不信任单次反馈信号，而是累积多次一致的反馈后才更新 DGD 权重。将"输入层先全存、靠使用频率筛选"的逻辑应用到反馈层：反馈先全收，靠反复出现来筛选。

## 问题背景

meomory 的 LLM Judge 反馈准确率约 70%——30% 的反馈是错误的。旧 CMS 用 α 衰减意外过滤了噪声（副作用），但 α 衰减本身摧毁了基础结构。去掉 α 后噪声过滤也没了。

需要一种**不依赖 α 衰减**的噪声过滤机制。

## 设计

```
现在：
  Judge 说"用了" → 立刻 DGD.update() → 可能是错的

改进后：
  Judge 说"用了" → 计数器 +1
  同一条关联累积 N 次"用了" → 才执行 DGD.update()
  单次错误反馈不伤害 M
```

## 核心要点

- 与其提升 Judge 的准确率（难，依赖模型能力），不如让 DGD 对不准的 Judge 更鲁棒（容易，只需累积计数）
- 这和记忆写入的逻辑一致：不做判断先全收，靠反复出现来筛选重要性
- 也和大脑一致：单次经历形成弱痕迹，反复经历才巩固为强关联
- 阈值 N 是一个新的超参数，需要实验确定

## 关联概念

- [[记忆写入]] — "全存不判断，靠使用筛选"的逻辑从内容层延伸到反馈层
- [[记忆迁移]] — 累积阈值本质上是反馈信号的"巩固"——从原始信号沉淀为可信信号
- [[多层有损压缩]] — 低于阈值的反馈被自然丢弃，这就是压缩中的遗忘
