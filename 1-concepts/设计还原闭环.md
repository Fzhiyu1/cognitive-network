# 设计还原闭环

**提出者**：fangzhiyu
**日期**：2026-04-08
**来源**：[[程序化UI还原闭环：从亚像素对齐实践到方法论]]

## 定义

设计还原闭环是一种将 UI 设计稿精确还原到代码的验证方法：通过程序化读取设计端（Figma 节点坐标）和渲染端（DOM getBoundingClientRect）的精确数值，计算偏差并归因到具体 CSS 属性，修改后立即重新测量，迭代直到亚像素级收敛。

核心原则：**两端都程序化**——设计真值和渲染真值都不依赖人眼或视觉模型，而是直接读数字。

## 核心要点

| 环节 | 工具 | 输出 |
|------|------|------|
| 设计真值 | Figma MCP `get_node_info` | absoluteBoundingBox, fontSize, lineHeightPx |
| 缩放映射 | ratio = targetWidth / designWidth | CSS 期望值（精确到 0.1px） |
| 渲染真值 | CDP `webview_evaluate` | getBoundingClientRect, getComputedStyle |
| 归因决策 | LLM 分析数值偏差 | 确定改哪个 CSS 属性、改多少 |
| 验证 | CDP 重新测量 | 偏差是否收敛 |

与多模态视觉对比的关键区别：精度从 2-3px（[[噪声鲁棒性与天花板|基线噪声]]）跃升到 0.02px，且方向判断无歧义。
