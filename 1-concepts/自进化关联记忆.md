# 自进化关联记忆

**提出者**：fangzhiyu + AI 协作
**日期**：2026年3月17日
**来源**：meomory FunSearch 类进化实验

## 定义

通过 FunSearch 群岛进化模型，让多个 AI 模型（qwen3.5:9b、DeepSeek、GPT-5.4）自动发现比人类手写更优的关联记忆算法。从标准 Hebbian 规则（P@1=26%）进化到融合 Adam 优化器 + 非线性查询 + 历史一致性奖励的混合算法（P@1=79.4%），全程无人工设计。

## 进化出的最优算法（gen019, 79.4%）

核心公式：
```
ΔM = momentum × vel + Adam(error_term + hebb_term + consistency_bonus)

其中:
  error_term = -η_adaptive × error × key          (纠错)
  hebb_term  = η_adaptive × target × key          (强化)
  consistency = 0.3η × prev_target × key           (历史一致性)
  η_adaptive = η / (1 + avg_error)                 (自适应)
  query      = M @ key + 0.1 × nonlinear(key²)    (非线性增强)
```

## 与原始 DGD 的区别

| | 原始 DGD (2025) | 进化版 (2026) |
|--|---------|----------|
| M 初始化 | Identity（直通） | Zero（白纸） |
| 学习信号 | 单项纠错 | 纠错 + Hebbian 强化（2x target） |
| 优化器 | 无 | Adam + Momentum |
| 学习率 | 固定 | 自适应（随 error 缩放） |
| query | 线性 M@key | 非线性（加 key² 项） |
| 额外状态 | 无 | velocity, Adam m/v, key/target history |

## 进化过程

```
标准 Hebbian (26.8%) — 人类设计
  → 零初始化 + Hebbian + 动量 (72.4%) — 9b 发现
    → + Adam + 非线性 + 一致性 (79.4%) — DeepSeek 发现
```

三个模型各自贡献：
- GPT-5.4 首先打开突破口（61.2%，32 槽记忆缓存）
- 9b 靠量发现核心策略（72.4%，零初始化 + Hebbian）
- DeepSeek 精细优化到最优（79.4%，Adam + 非线性）

## 发现的意义

1. **组件都是已知的**（Adam 2014, Hebbian 1949, Momentum 1980s），但这个具体组合没有人做过
2. **零初始化反直觉**——所有文献都用 Identity 初始化，LLM 发现从零开始更好
3. **双倍强化信号**——不只纠错，还额外强化正确关联，这和生物学习双通道模型吻合
4. **AI 发现 AI 算法**——没有人类设计参与，纯粹通过进化搜索
