# 提示词进化实验

**提出者**：fangzhiyu
**日期**：2026年3月17日
**来源**：meomory Judge prompt 进化搜索实验

## 实验概述

用遗传算法（GA 交叉+变异）自动进化 meomory 的 Judge prompt，在 200 个样本上评测 feedback accuracy，15 代进化。

## 两组实验对比

### V1: Usage-based（"agent 用了哪个记忆"）

| 阶段 | best accuracy | avg accuracy |
|------|:---:|:---:|
| 原始 baseline | 28.9% | - |
| 种子 (Gen 0) | 43.1% | 34.8% |
| Gen 5 | **66.7%** | 48.1% |
| Gen 15 (最终) | **66.7%** | 54.0% |

进化谱系（3 步到达最优）：
```
seed-004 (43.1%) — 手写变体，强调"specific claim, fact, or detail ONLY found in that fragment"
  → gen004-000 (61.1%) — GA 交叉，加了"rigorous"判断标准
    → gen005-006 (66.7%) — GA 交叉，加了"genuinely and exclusively referenced"
```

关键进化方向：从模糊的"determine which memories were used" → 严格的"specific claim ONLY found in that fragment" → "genuinely and exclusively referenced"。

### V2: Relevance-based（"哪个记忆和答案相关"）

| 阶段 | best accuracy | avg accuracy |
|------|:---:|:---:|
| 种子 (Gen 0) | 78.6% | 56.0% |
| Gen 8 | **90.9%** | 86.5% |
| Gen 14 | **90.9%** | ~89% |

V2 改变了评测目标：不模拟 agent 回答，直接问"哪个记忆包含答案"。起点就比 V1 高（78.6% vs 43.1%），最终到 90.9%。

最优 prompt 进化出了 7 条严格规则：
1. DIRECT ANSWER REQUIREMENT
2. SELF-CONTAINED COMPLETENESS
3. NO COMBINATION ALLOWED
4. NO TOPICAL FALLACY
5. NO PARTIAL CREDIT
6. VERIFIABLE INFORMATION
7. STRICT INTERPRETATION

## 核心发现

1. **Prompt 措辞对准确率影响巨大**：光是换个种子 prompt（不进化），从 28.9% 到 43.1%（+14pp）
2. **进化有效但会饱和**：V1 在 Gen 5 到顶，V2 在 Gen 8 到顶，后面几代 avg 在涨但 best 不动
3. **评测目标比进化策略更重要**：V2 改了问法（usage → relevance），起步就比 V1 最终结果高（78.6% > 66.7%）
4. **LLM 自动发现的规则比人写的好**：7 条进化规则比人手写的 4 条规则精度高一倍
5. **种群整体提升**：V2 avg 从 56% → 89%，说明不是一个突变撞大运

## 待验证

- **过拟合风险**：进化和评测用同 200 个样本，90.9% 可能虚高
- **泛化验证**：需要在 hold-out 1776 题 + 跨数据集（DialSim）上测试
