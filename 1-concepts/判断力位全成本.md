# 判断力位全成本

**提出者**：fangzhiyu & Claude（Opus 4.7）
**日期**：2026-05-13
**来源**：[[2026-05-13-AI决策的反向能力]]

## 定义

人类直觉里计算 AI 替代人的账，是单项的：

```
某任务成本 = 人工时 × 时薪
AI 做相同任务 = token 成本
```

这个账漏算了一项：[[判断力位]] 的维护成本。真实账目是：

```
AI 替代的全成本 = token 成本 + 判断力位维护成本
                              ↑
              如果位子空了或假装有人坐着，
              短期账面省钱，长期 [[校准的不可外包性]] 开始收账
```

## 为什么这项成本会被漏算

[[判断力位]] 的维护成本具有三个属性：

| 属性 | 表现 |
|---|---|
| **延迟** | 不在当季财报上显示，要几个季度甚至几年才显现 |
| **不可见** | 没有直接计量单位，要等大事故倒推 |
| **累积** | 每次跳过一点判断动作，品味就退化一点，下次判断更难 |

具备这三个属性的成本，在标准会计/KPI 系统里**结构性地被低估**——不是算错，是看不见。

## 位子的三种状态

| 状态 | 短期账面 | 长期结果 |
|---|---|---|
| 真有人坐 | 成本高 | 品味持续生长，校准信号闭环 |
| 假装有人坐（橡皮图章） | 成本低 | 品味停滞，校准信号哑掉，等大事故 |
| 位子空着（AI 自主） | 成本最低 | [[AI镜像陷阱：当创造者只消费AI的产出]] 退化路径，系统不可见地降级 |

中间那行最危险——账面 KPI 漂亮，所以最容易被组织选择，但代价被推到不可见的未来。

## 为什么 AI 不能坐进位子

[[知道与推测不分]] 和 [[没有前额叶的皮层]] 没解决之前，AI 坐进位子也长不出品味：

```
人坐 → 做判断动作 → 产生品味 → 下次更准（闭环）
AI 坐 → 做判断动作 → 产生看起来像品味的输出 → 下次还是从训练分布里采（开环）
```

AI 坐的位子是个**摆设**。它执行了形式上的判断动作，但产物（品味）没有积累者，因为积累需要那个监控信号——"我刚才是知道还是猜的"——而那个信号不存在（参见 [[单向决策系统]]）。

即使造出"前额叶层"，也是 [[借来的权威]]：通过外观审计但不真承担。

## 替代的实际形态

把全成本算对之后，"AI 替代人"的真实均衡不是 AI 把人都赶走，而是**判断力位被重组**：

1. **执行层**：大量人被 AI 替代（这部分是真的，会继续）
2. **判断层**：人数变少，但单位人承担的判断密度急剧上升
3. **金字塔压扁**：中间层（执行+部分判断）萎缩，顶层（纯判断）人均产能放大、人均权重也放大
4. **隐性风险**：组织和社会如果没意识到判断层不能空，可能会一并裁掉——然后进入退化路径，等大事故

## 价值通胀与通缩的不对称

未来贵的不是"能用 AI 的人"，是**能判断 AI 输出对不对的人**：

- 前者会**通胀**——技能门槛越来越低，供给会扩张
- 后者会**通缩**——品味只能在做判断动作的过程中长出来，而越来越多人主动从位子上下来

不是技能稀缺，是**位子稀缺**——大多数人放弃了坐位子的动作。

## 实践含义

- 算 AI ROI 时把"判断力位维护"作为一个显式条目，哪怕没法精确定价
- 设计组织时把判断层和执行层分开处理，避免一起裁
- 个人层面：识别哪些位子值得继续坐——不是"还能不能省下来"，是"坐这个位子能不能让我长出品味"
- 警惕橡皮图章状态：人在位子上但实际只是过审 AI 输出，这种"假装有人坐"比"位子空着"更危险——因为它消耗会计预算却不产生品味
