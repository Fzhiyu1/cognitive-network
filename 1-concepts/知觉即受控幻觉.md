# 知觉即受控幻觉

大脑是生成模型（渲染器），你看到的永远是它的输出——传感器数据只用来算残差、纠偏内部状态，从不直接"显示"。工程上的最小版本是卡尔曼滤波：prior rollout → 观测 → 残差 → posterior 修正。

由此，意识状态谱系统一为**一个标量参数的取值**（precision weighting，感官权重）：

- 感官权重正常 → 清醒知觉
- 权重→0、元认知也下线 → 梦（open-loop 误差累积，所以怪诞——与视频生成模型长程漂移同构）
- 权重→0、元认知在线 → 清醒梦
- 权重被强制切断、渲染器爆发运行 → 濒死体验（"比真实更真实"= 满置信度写入、无残差盖戳）
- 权重交接时的毛刺 → 入睡振动阶段（感官移交的握手噪声）

先验权重病理性过强 → 幻觉；被压低 → 迷幻剂状态（REBUS）。冥想在此框架下的精确定义：**手动调 precision weighting 的练习**——这解释了为什么音频内容型冥想 App 无效（内容不改权重，注意力训练才改）。
