# Vibe Coding 上瘾

**提出者**：fangzhiyu
**日期**：2026-03-21
**来源**：[[AI镜像陷阱：当创造者只消费AI的产出]]

## 定义

Vibe coding 与短视频共享同一套即时反馈上瘾机制（低投入、高刺激、快反馈），但因为产出了代码而更具隐蔽性。创造者误以为自己在工作，实际上在消费 AI 的能力而非积累自身能力。

## 历史独特性

每个时代的上瘾对象——小说、电视、短视频——都有一个共同点：你在接收**外部信息**。Vibe coding 不同：你没有在消费别人的创造，也没有在真正创造。

它是人类历史上第一种**伪装成生产力的自我回音上瘾**。

## 核心要点

判断标准：
- **有目标的 vibe coding** = 工具（有明确需求，AI 提效）
- **无目的的 vibe coding** = 上瘾（随便起项目，看效果，换一个）

识别信号：停下来时感到空虚；不停起新项目但不做完；感觉写代码变得"廉价"。

解法不是戒断，是**加约束**：写之前先想清楚要做什么，逼自己手写关键逻辑，一个项目做完再开下一个。
