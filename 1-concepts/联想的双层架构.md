# 联想的双层架构

**提出者**:fangzhiyu
**日期**:2026-05-03
**来源**:[[lens+wake首次运行：元认知循环的实例化]] 之后,对 wake 误召回的架构性反思

## 核心洞察

当前 wake 把"主动联想该做的事"放到了"自动前馈"位置——所以工程问题、闲聊都被强行联想。**正确的架构是分层**:

| | L0 用户侧 / 前馈 | L1 模型侧 / 主动 |
|---|---|---|
| **触发** | 用户每次发消息(lens 自动) | AI 在生成中识别需要(MCP) |
| **机制** | wake-light(自动注入) | `mcp__wake__memory_recall` |
| **类比** | System 1 / [[前意识激活层]] / 玛德琳触发 | System 2 / 显式回忆 / 反思 |
| **应做** | 浅激活——"可能相关的形状"进入可用 | 深展开——真正需要时才调 |
| **不该做** | 深联想、解释、重解 query | 自动触发(代价高) |

## L0 浮现应携带 first-order 描述

**裸概念名 ≠ 玛德琳激活**。人脑前意识激活的不是"花朵"两个字,是"花朵很香,尤其是春天"这个**带 first-order 属性的整体**。

正确格式:
```
[[多层有损压缩]] —— substrate 引力中心,50入边
[[关联记忆]] —— 一个矩阵存所有,看不见原始事件
```

刚好对应 KB 的 `INDEX.md` 格式(每卡一行 summary)——L0 模式可直接复用 INDEX,甚至不需要 LLM 调用。

## 这个架构与已有理论同构

- **Kahneman 双过程**:System 1(自动/快/不可拒绝) vs System 2(主动/慢/可否决)
- **LeDoux 双路径**(恐惧反应):thalamus→amygdala 快路径 vs thalamus→cortex→amygdala 慢路径
- **Friston 自由能**:快推断(固定先验) vs 慢推断(active inference)
- **玛德琳**:味道触发 → 整段记忆形状自动浮现(L0) → 然后坐下来追问"为什么这味道让我想到那个夏天"(L1)

## 为什么这个分层解决误召回

| 失败 case | 当前架构 | 双层架构 |
|----------|--------|---------|
| 工程问题 "压缩文件" | wake 强行哲学化 → 污染 | L0 给标签,Claude 判断"工程问题不需要深挖" → 直接答 |
| 词面陷阱 "我想跑个步" | wake 错联想 [[可行动状态]] | L0 给标签,Claude 自己决定要不要用 |
| 指代 "继续" | wake 看不到上下文,瞎 —— | L0 从对话历史给"上轮活跃概念" |

关键:**把"深度判断权"还给 Claude**——它有完整对话上下文,能判断当前 query 需要浅激活还是深召回;wake 在 lens 端只看 500 字 query,没这个判断力。

## 实操方案

```
wake daemon 加 mode 参数:
  --mode=light → 输出"卡名 + 一行 gloss",<50 字
  --mode=deep  → 当前的联想风格(完整版)

lens wake_memory plugin 切到 light
MCP memory_recall 用 deep
```

工作量 3-4 小时。

## 优先级判断(2026-05-03)

实测 [[注入的石子灰尘针叶调味料模型]] 表明:Claude 对灰尘式注入会自己过滤,对调味料会化为风格——双层架构的紧迫性比初判低。**先观察一段时间,再决定要不要做**。
