# 进化突破人类认知偏见

**提出者**：fangzhiyu
**日期**：2026年3月17日
**来源**：meomory FunSearch 类进化实验中的意外发现

## 定义

当 AI 通过进化搜索优化算法时，它不受人类先前实验结论的约束，能够发现人类因认知偏见而排除的有效方案。进化没有"之前试过不行"的记忆包袱。

## 核心案例：α=0.999

### 人类的推理链

```
实验 1: α=0.9  → P@1=1.3%   崩了
实验 2: α=0.95 → P@1=1.1%   崩了
实验 3: α=0.99 → P@1=1.1%   崩了
实验 4: α=1.0  → P@1=26.6%  唯一能用的

结论: α<1.0 = 死亡谷，绝对不能用
```

这个结论在标准 Hebbian 规则下是**正确的**。

### 进化的发现

```
进化第 57 代: α=0.999 + momentum + bias + gain + BatchNorm
             → P@1=87.6%（500题）/ 49.5%（全量）

比 α=1.0 的标准 Hebbian（26.8%）高了 60pp
```

**α=0.999 在新的算法结构下不仅不崩，反而是最优的。**

### 为什么人类不会发现这个

1. **锚定效应**：一旦证明"α<1.0 会崩"，人类不会再尝试 α<1.0
2. **条件忽视**：结论"α<1.0 会崩"的前提是"标准 Hebbian 规则"，但人类会忘记这个前提，把结论泛化
3. **局部经验覆盖全局**：在简单规则下的实验结论，被不当推广到所有规则
4. **工程惯性**：[[工程惯性覆盖]] 的又一个例子——之前的发现反而变成了障碍

### 进化为什么能突破

- 进化不读论文、不看之前的实验结论
- 每个候选独立评测，纯看分数
- 不存在"这个参数之前试过不行"的心理障碍
- 会同时改变多个变量（α + 结构），而人类习惯控制变量逐个测试

## 更广的启示

这不只是一个参数的事。进化出的 87.6% 算法有多个"人类不会尝试"的设计：

| 设计选择 | 人类直觉 | 进化的选择 | 为什么人类不会试 |
|---------|---------|-----------|---------------|
| M 初始化 | Identity（直通） | **Zero（白纸）** | "不初始化怎么检索？" |
| α 值 | 1.0（死亡谷证据） | **0.999** | "证明了 <1.0 会崩" |
| 给 key 加 BatchNorm | 不会（"这不是图像分类"） | **加了** | 领域偏见 |
| 给输出加 bias+gain | 不会（"关联记忆不需要"） | **加了** | 传统框架限制 |
| 同时改 5 个组件 | 不会（"控制变量"） | **同时改** | 科学方法论限制 |

## 认知科学解释

这对应 Kahneman 的 **WYSIATI（What You See Is All There Is）**：

- 人类只基于已知信息做判断（"α<1.0 在 Hebbian 下崩了"）
- 不考虑未知的可能性（"α<1.0 在其他规则下可能好"）
- 进化没有这个偏见，因为它不"看"之前的结论，只看评测分数

## 对研究方法的启示

1. **实验结论都有隐含前提** — "α<1.0 会崩"的前提是"标准 Hebbian"，换了结构可能不成立
2. **控制变量法有局限** — 逐个测试找不到需要同时改变多个变量才能生效的方案
3. **进化搜索是对冲人类偏见的工具** — 不是替代人类思考，是补充人类思考的盲区
4. **"已证伪"不等于"永远错"** — 条件变了，结论可能翻转
