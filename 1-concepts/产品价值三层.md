# 产品价值三层

**提出者**：梁宁
**日期**：2026-07-30
**来源**：[[真需求 - 梁宁]]

## 定义

```
产品价值 = 功能价值 + 情绪价值 + 资产价值
```

三层各自对应一类需求，各有自己的成立条件和死法。任何产品都可定位在这个三维空间里，创新即在原有价值上叠加新层次。

## 核心要点

### 功能价值 — 效率需求

客观、可参数化、可标准化交付。实质是**基础需求 + 效率需求**。用户诉求是"更高效、更便宜"，即性价比。四种模型：

| 模型 | 例子 |
|------|------|
| 原材料 / 劳动力 | 卖大米 |
| 专利 / IP | 司美格鲁肽 |
| 平台 / 供应链 | 石油 |
| 基础设施 | 电 |

时代更迭以基础设施更迭为标志，因此基础设施之争是王者之战，且一旦成为基础设施就要被套上社会责任的枷锁。

### 情绪价值 — 情感需求

```
情绪价值 = 生理唤起 + 认知标记 + 心理账户
```

主观，千人千面（汝之蜜糖彼之砒霜）。三个付费点：**保障感**（对抗担心）、**愉悦感**（对抗枯燥）、**彰显性**（对抗自卑）。

心理账户决定是否付费以及付多少——"爱因斯坦的脑子"卖 5 毛能卖 10 万单，而上一辈人因为没有这个心理账户，只会认为是骗人。

### 资产价值 — 投资需求

判据极简：**可持续变现，就有资产价值**。需要两个条件：

1. 有可供持续变现的专门市场 / 二手市场及配套服务
2. 它在该市场的价值与价格依赖于某个共识

因此人造钻石压低价格不是价值创造而是价值毁灭：毁灭稀缺性即毁灭彰显基础，混淆真假即摧毁二手市场赖以运转的鉴定与共识。

## 组合规律

- **功能类产品不断整合**（洗衣柔顺保养三合一吃掉洗衣液），**情绪类产品不断分化**（旅游鞋分化成跑步鞋、登山鞋、溯溪鞋……）
- 消费升级的核心动作就是在功能价值上叠加情绪价值
- 只有情绪价值而没有功能价值锚定的产品不够犀利——六个核桃靠"补脑"的功能想象获得消费确定性，才成为百亿单品
