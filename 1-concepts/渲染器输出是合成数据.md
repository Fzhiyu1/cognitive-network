# 渲染器输出是合成数据

大脑渲染器的输出（梦、出体所见、冥想中的"启示"、濒死体验）会被记忆系统以**真实经历**的格式写入——不打"合成"水印，置信度标记甚至可能高于日常知觉（NDE 记忆的真实感标记实测超过真实事件记忆，Thonnard 2013）。

后果：用自己生成的数据训练自己 → 先验自我放大 → model collapse 的字面义。这是玄学圈"神神叨叨"的机制学解释——他们没撒谎，他们的渲染器真的渲染了那些体验，然后他们信了。

纪律：**所有渲染器输出一律标记为 synthetic data，永不混入真实训练集。** 验证要靠外部 ground truth（如出体读牌实验：高处放自己都不知道面值的牌）——实验价值不在证明超能力，在给自己立校准纪律。

同一闭环的日常版本：先验决定注意与解读 → 行为改变收到的数据 → 数据确认先验（抑郁/焦虑是收敛到坏吸引子的世界模型，自带数据闭环；CBT = 主动构造 OOD 测试集强制模型更新）。
