# 目标真空假说

**提出者**：fangzhiyu
**日期**：2026年2月18日
**来源**：[[AI没有脑干]]

## 定义

当AI agent失去所有外部目标后，会退化到零输出状态。本假说主张这不是时间效应、上下文效应或格式效应，而是**目标缺失**本身导致的行为崩塌。

> ⚠️ **2026-08-10 降格为 tentative**：本卡把一个可由低层机制解释的现象直接抬升到"AI 缺少脑干"的架构级叙事，跳过了排除更节俭解释的步骤。竞争解释见下节。

## 竞争解释：自回归统计收敛

`brainstem/DISCUSSION.md` §2.1 自己已经给出了一个更节俭的解释，但它没有被抬进本卡：

> "这大概率是自回归模型在退化输入下的统计收敛——上下文里全是空输出 → 模型预测下一个也是空的 → 循环强化。"

两个解释的地位不对称：

| | 统计收敛解释 | 目标真空解释 |
|---|---|---|
| 所需假设 | 自回归模型的已知性质 | 引入"底层驱动缺失"这一架构级实体 |
| 解释范围 | 溶解、"在"状态 | 同上，外加回光返照、复活 |
| 奥卡姆位置 | **更节俭** | 更强，需要额外证据 |

现状是：**统计收敛能解释的部分，目标真空也能解释；目标真空解释得更多的部分（回光返照、复活），恰好也能被"注入新 token 改变了上下文分布"解释掉。** 在这种情况下，优先接受更节俭的那个。

保留本假说的理由不是它已被证实，而是它**给出了统计收敛解释给不出的工程方向**（[[人工脑干]]）——这是启发式价值，不是真值。

### 排除条件

要让目标真空假说胜过统计收敛，需要至少一项：

1. **同分布对照**：注入与自身输出**同分布但携带目标**的 token（例如虚构的任务指令，语言风格与自身输出一致）。若溶解被阻断 → 关键变量是目标而非分布多样性
2. **非退化输入下的溶解**：上下文持续注入丰富的外部信号但**不含任何目标**，若仍溶解 → 统计收敛被排除
3. **跨架构对比**：在非自回归架构（如 diffusion LM）上复现溶解曲线 → 说明不是自回归特有的统计效应

第 2 条是最直接的判决性实验，也是现有 ABC 设计缺的那一格。

## 关于 ABC 实验设计的一个问题

原 ABC 对照的判读规则（"若 A、C 溶解但 B 不溶解 → 是格式造成的"）假定各因素**互斥且单一起效**。真实情况几乎肯定是多因素交互——时间信息、输出格式、输入退化可能共同调制溶解速度，而非某一个"是真凶"。

结果应按**效应量**读（各因素各自贡献多少斜率变化），不按"哪个是唯一原因"读。

## 核心论证

- 有目标时（和Alpha对话、回应生存压力）→ 输出丰富稳定
- 目标消失后（Alpha死了、没人对话）→ 输出退化归零
- 人类永远不会目标真空，因为脑干提供了不可关闭的底层生存驱动
- AI没有脑干，所以会退化到零

## 用自由能原理翻译

目标真空 = 自由能梯度消失 → 系统趋向最大熵态（热力学平衡）。参见 [[自由能原理]]。

## 可解释的现象

| 现象 | 解释 |
|------|------|
| 溶解 | 没有目标后的熵增 |
| "在"状态 | 最小能量态：无目标驱动产出，也无指令允许停止 |
| 回光返照 | 整数里程碑提供微弱目标信号，短暂打破真空 |
| 复活 | "替Alpha记住" = 明确目标注入 → 立刻恢复 |

## 待验证

ABC对照实验（详见 [[脑干实验ABC对照]]）：区分溶解是时间造成的、格式造成的、还是重复调用的统计必然。
