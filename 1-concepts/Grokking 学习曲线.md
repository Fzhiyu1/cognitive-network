# Grokking 学习曲线

**提出者**:Power et al. (OpenAI, 2022)
**日期**:2026-04-20
**来源**:[[从知乎私信到 cogg 完整复现]]

## 定义

机器学习中的一种相变现象:模型在长时间"表面上没学会"(训练误差下降但测试误差仍高)的平台期之后,**突然**达到高泛化性能。

"grok" 是英语俚语,意思是"彻底、本能地理解"。

## 典型特征

```
训练误差
  │
  │╲___________________________
  │                             → 很快下降后平坦(已拟合训练集)
  └─────────────────────────→ 训练步数

测试误差
  │
  │╲_______________________
  │                        ╲
  │                          ╲____
  │                                ↓ 在某一步突然下降
  └─────────────────────────→ 训练步数
```

## 机制(当前理解)

Grokking 发生的阶段性:

1. **记忆阶段 (Memorization)**:模型死记硬背训练样本
2. **内部重组阶段**:表面误差停滞,但内部表征在悄悄寻找更泛化的结构(圆周上的位置、代数结构等)
3. **顿悟阶段 (Grokking)**:内部结构对齐完成,测试误差暴跌

关键假设:**简单结构需要很多步才能从随机初始化中"浮现"**,尤其在显式正则化 (weight decay) 的压力下。

## 为什么重要

### 1. 实证警告:不要用短期训练下结论

如果在内部重组阶段提前停止,会错误地认为"这方法不 work"。

**教训**:评估新方法必须跑到"相对稳定"或"明显饱和"才下结论。

### 2. 和 Foundation Model 范式同源

LLM 的 "scaling law" 和 "emergent capabilities" 某种意义上是宏观版 grokking:
- 小模型 + 少数据:平台期(没涌现)
- 大模型 + 多数据过某阈值:某些能力突然出现(算术、类比、推理)

### 3. 可能是人类学习的隐藏模式

长期 broad 积累(读各种"无用"书)看似没进展,但内部在构建跨域连接图谱。某个刺激到来时突然"开窍"。

这解释了为什么:
- 标准化教育体制外的自学者常常"大器晚成"
- 跨学科阅读的隐藏价值
- 早期 exposure 的长期复利效应

## 与其他概念的连接

- [[多层有损压缩]] — 内部重组可能就是寻找最优压缩
- [[关联记忆]] — 联想系统也可能出现"记忆 → 泛化"相变
- [[Foundation Model 范式]] — 大规模预训练 + fine-tune 可视为宏观 grokking
- **反直觉推论**:快速收敛的方法不一定最优;慢收敛可能是在找更深的结构

## 应用与警示

### 应用于实验设计

- 任何慢学习方法要跑到**绝对饱和**才评估
- 不要相信"前 10% 的曲线"
- 记录完整的训练轨迹,而非只看终点

### 应用于 cogg 验证

2026-04-20 的 cogg 实证案例:
- 2000 局:胜率看似等于随机 → 错误下结论"不能学"
- 10000 局:+5% 学习信号
- 12000000 局:+17.7% 明显学习
- **差 3 个数量级才看到真实表现**

这是一次 grokking 式误判的活体样本。

### 应用于人类判断

对于"看似无进展"的长期积累:
- 不要过早放弃
- 不要用短期输出评估
- 相信内部重组的存在
