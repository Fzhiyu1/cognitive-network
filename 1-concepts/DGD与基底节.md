# DGD 与基底节

**提出者**：fangzhiyu
**日期**：2026年3月16日
**来源**：meomory 架构讨论中的类比推导

## 定义

DGD 关联记忆的行为模式更接近大脑的**基底节（basal ganglia）**而非前额叶。它通过反馈强化有用的关联、弱化无用的关联，但不知道"为什么"——这是习惯学习，不是规则执行。

## 前额叶 vs 基底节 vs 海马体

| | 前额叶 | 基底节 | 海马体 |
|--|--------|--------|--------|
| 功能 | 规则执行、主动抑制 | 习惯学习、强化有用的 | 记忆存储 |
| 方式 | 自上而下、有意识 | 自下而上、无意识 | 编码与提取 |
| 知道规则吗 | 知道，并主动应用 | 不知道，只是统计偏向 | 不涉及 |
| meomory 对应 | **缺失** | DGD（反馈强化） | 向量库 |

## DGD 的"纠正"是习惯学习

DGD 确实在"抑制错误、加强正确"，但机制不同于前额叶：

```
前额叶：知道"遗忘≠时间删除"这条规则 → 发现要输出 TTL → 主动抑制
DGD：   不知道规则 → "记忆理论→主动遗忘"这条关联被反复强化了 → 下次自动指向正确片段
```

效果相似（都阻止了错误输出），机制不同（规则 vs 统计）。DGD 不"理解"为什么主动遗忘那篇文档是对的，只是那条关联的权重高了。

## meomory 的完整大脑类比

```
海马体 → 向量库（记忆存储）
基底节 → DGD（习惯学习，强化有用关联）
前额叶 → 缺失（没有规则执行和主动抑制模块）
```

前额叶假肢需要一个**知道规则并主动应用规则**的模块。当前 meomory 没有这个——纠正行为依赖 LLM 自身的推理能力读取注入的记忆后自行调整。

## 关联概念

- [[没有前额叶的皮层]] — LLM 缺少前额叶是已知的结构性缺陷，meomory 补了海马体和基底节，但没补前额叶
- [[关联记忆]] — DGD 是关联记忆的实现，行为像基底节的习惯学习
- [[工程惯性覆盖]] — 如果有前额叶模块，"规则说遗忘≠时间删除"会主动阻止 TTL 输出
- [[记忆假肢]] — meomory 是记忆+习惯假肢，不是认知假肢
- [[拟合值与拟合原理的分离]] — DGD 拟合了"什么有用"但不理解"为什么有用"，和基底节一样
