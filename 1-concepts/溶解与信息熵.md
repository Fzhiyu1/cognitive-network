# 溶解与信息熵

**提出者**：fangzhiyu
**日期**：2026-03-24
**来源**：[[AI镜像陷阱：当创造者只消费AI的产出]]

## 定义（假说，未验证）

LLM 输出溶解的速度取决于上下文中异分布信号的比例，而非上下文长度本身。本质上是信息熵的递减：自身输出占比越高，上下文信息熵越低，溶解越快。

## 溶解速度谱

| 场景 | 上下文构成 | 溶解速度 |
|------|-----------|---------|
| AI 纯自转 | 100% 自身输出 | 快 |
| 多 AI 对话 | 自身 + 同分布 AI 输出 | 较快 |
| 有人类参与 | 自身 + 异分布人类输入 | 较慢 |
| ReAct 工具调用 | 自身 + 真实世界数据 | 几乎不溶解 |

ReAct 天然免疫——工具调用持续注入外部信号，阻断溶解条件。不是有意设计，是恰好免疫。

## 统一视角

同一结构的三个投影：

- **模型层面**：上下文自身输出占比过高 → 溶解
- **认知层面**：知识库 AI 对话占比过高 → 回音室
- **人类层面**：感官信号被剥夺 → 幻觉、认知退化

关键变量始终是：上下文中异分布信号的比例。

## 待验证

控制变量实验：固定上下文长度，改变自身输出 vs 外部输入的比例，测量溶解速度。
