# 进化搜索记忆系统

**提出者**：fangzhiyu
**日期**：2026年3月17日
**来源**：meomory 大规模实验后的方向讨论，受 DeepMind FunSearch 启发

## 定义

用群岛进化模型（Island Model）+ LLM 生成变异，自动搜索记忆系统中的最优组件——特别是反馈判断逻辑（Judge Prompt）和关联学习规则（DGD Update Rule）。

## 为什么需要进化搜索

meomory 大规模实验（2446 题）揭示了一个结构性问题：

```
DGD-GT（完美反馈）  → P@1 = 32.8% / 56.0%   ← 学习规则没问题
DGD-Judge（自动反馈）→ P@1 = 24.5% / 50.0%   ← 反馈质量是瓶颈
                                                  feedback accuracy 33-43%
```

人工设计 Judge prompt 难以突破 50% 准确率。进化搜索可以在巨大的 prompt 空间中自动发现更好的判断逻辑。

## 两个进化目标

### 目标 1：Judge Prompt 进化（高优先级）

- **搜索空间**：Judge 的 system prompt + user prompt 格式
- **适应度函数**：feedback accuracy（Judge 判断 vs GT 标签的一致率）
- **评测成本**：极低，不需要跑完整 DGD 循环
- **候选变异**：问法改变、分级 vs 二元、CoT 推理、多 Judge 投票、语言切换

### 目标 2：DGD 更新规则进化（低优先级，等 Judge >60%）

- **搜索空间**：更新规则的 Python 代码
- **适应度函数**：P@1（GT 反馈下）
- **评测成本**：~1 分钟/个
- **候选变异**：动量、负反馈、对比学习、残差连接、门控、多头、低秩分解

## 群岛进化架构

```
N 个岛（各维护 top-K 候选）
  ↓
LLM 生成变异（基于岛内最优 + 随机扰动）
  ↓
自动评测（已有的 benchmark pipeline）
  ↓
选择（淘汰最差，保留最优）
  ↓
迁移（每 G 代，岛间交换最优解，保持多样性）
  ↓
重复 100-500 代
```

## 与 FunSearch 的异同

| | FunSearch | meomory 进化搜索 |
|--|----------|-----------------|
| 搜索目标 | 数学函数 | Judge prompt / DGD 规则 |
| 评测 | 数学验证（绝对正确） | benchmark 分数（有噪声） |
| LLM 角色 | 生成候选程序 | 生成候选 prompt / 代码 |
| 进化模型 | 群岛 | 群岛（相同） |
| 风险 | 低（数学可验证） | 过拟合当前数据集 |

## 前置条件

1. Judge prompt 进化：**现在就可以做**（基础设施齐全）
2. DGD 规则进化：需要 Judge accuracy >60% + 5 个以上数据集
