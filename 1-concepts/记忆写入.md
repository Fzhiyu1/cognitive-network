# 记忆写入

**提出者**：fangzhiyu
**日期**：2026年3月16日
**来源**：[[从记忆理论到状态恢复：meomory原型的设计基础]]

## 定义

记忆写入是记忆系统中"新信息怎么进入记忆"的问题。与记忆检索（查）和记忆注入（读）并列为记忆系统的三个核心操作。

## 核心设计（2026-03-16 确定）

### 被动 + 主动混合写入

和人类一样，记忆写入分两种：
- **被动写入**：每轮对话自动存入输入层，不做判断，全部进入，立刻可被检索
- **主动写入**：用户触发（"记录一下"）或 agent 标记重要内容，质量更高

两种写入进同一个向量库，DGD 不区分来源——有用的被强化，没用的在巩固压缩中自然丢失。

### 不需要 TTL

遗忘不是"时间到了就删"，是**压缩的副产品**（[[多层有损压缩]]）。时间本身不造成遗忘，新信息涌入 + 巩固压缩 + 容量有限 = 细节必然丢失。因此：
- 不设 TTL（硬删除）
- α=1.0（DGD 不主动遗忘）
- 遗忘只在巩固的压缩过程中产生

### 立刻生效

写入不是"存进去等巩固"——写入的东西**立刻可被 DGD 检索到**。就像人类早上听到"下午 3 点开会"，不需要等晚上睡觉巩固，下午 2 点就能想起来。

### 写入不是覆盖，是压缩合并

新信息不覆盖旧记忆，而是在巩固时和旧记忆一起压缩成更丰富的理解：
- 覆盖："喜欢棉花糖" → "不喜欢棉花糖"（丢失历史）
- 压缩合并："曾经喜欢棉花糖，因为 X 事件后不再喜欢"（保留转变和因果）

## 完整生命周期

```
对话中 → 新信息实时写入（被动/主动）→ 立刻可检索
使用中 → DGD 反馈强化有用的片段
睡觉时 → 巩固：被反复激活的压缩升级为概念层，细节在压缩中丢失（遗忘）
```

## 市面方案对比

| 方案 | 思路 |
|------|------|
| MemGPT/Letta | agent 自己调 save_memory 工具 |
| SimpleMem | 全存，事后语义密度过滤 |
| A-Mem | Zettelkasten 动态索引+链接 |
| VCP | AI 在回复中自标记 + 文件监听 |
| **meomory** | **被动+主动混合，不删除，遗忘只在巩固压缩中产生** |

## 待验证

α=1.0（不主动遗忘）是目前唯一测过的值。需要对比 α=0.95/0.9 验证"遗忘只在巩固中产生"是否确实最优，还是 DGD 层面的轻微遗忘也有价值。
