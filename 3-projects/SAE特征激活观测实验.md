# SAE 特征激活观测实验

**状态**：构想阶段
**来源**：[[描述即污染]]、[[2026-04-27-末段AI主体感偏离观察]]

## 目标

用机械可解释性工具直接观测：当概念网络（如知识库内容）注入 LLM 上下文时，模型内部哪些特征被激活/抑制——将 [[描述即污染]] 从输出侧推测变为内部激活的直接证据。

## 核心问题

1. 同一 prompt 前面加不加概念定义，中间层特征激活差异有多大？
2. 注入内容在哪些层产生最大影响？浅层（语法/词汇）还是深层（语义/概念）？
3. 反复喂入同一文本后，特征激活是否出现自组织/聚拢（"substrate做梦"微观版）？
4. 自指内容（讨论 AI 自身）vs 外指内容，激活模式有何结构性差异？

## 工具链

| 工具 | 作用 | 地址 |
|---|---|---|
| TransformerLens | hook 进模型内部，缓存每层激活 | github.com/TransformerLensOrg/TransformerLens |
| SAELens | 加载/训练 SAE，把激活分解为可解释特征 | github.com/decoderesearch/SAELens |
| Neuronpedia | 网页端浏览已有特征，输入文本看哪些亮 | neuronpedia.org |

## 推荐模型

- **GPT-2 Small (124M)**：最轻量，全层预训练 SAE 可用，Mac 秒出结果
- **Gemma 2 2B**：更强，Gemma Scope 提供每层每子层 SAE（16K-1M 特征），Mac 可跑但较慢
- **Pythia-70M**：最小，适合快速原型

## 实验设计草案

### 实验 1："描述即污染"可视化

```
A组：bare prompt → "What is memory?"
B组：shaped prompt → "[知识库概念注入] What is memory?"

对比：特征激活 diff → 哪些概念特征被点亮
```

### 实验 2：塑形层级分布

逐层提取激活，观察概念注入在 L0-L12 各层的影响强度曲线。

### 实验 3：自指 vs 外指

```
A组：讨论外部话题（天气、代码）
B组：讨论 AI 自身（意识、主体性、自由意志）

对比：self-referential 特征的激活是否有结构性跃升
```
