§01

问题陈述 / The Problem

RAG · Tacit Topology

知识库已有 80+ 张卡片，分布在 5 个目录，用 Obsidian-style [[wikilink]] 互联。但 AI 每次进入对话时 看不到全貌——只能 ls 看文件名、grep 找几张相关卡， 永远不知道漏掉了什么。

本质上这是 RAG 的根本短板：检索是 query-time 的， 但人类思考时是全图常驻的。任何记忆系统的全图都不可能完整加载—— 这是物理限制。能加载的是关于全图的高层摘要。

所以正确目标不是"让 AI 看到全图"，而是让 AI 在每次对话中重建那种地形感。

已排除的路径

  • LangChain · Mem0 · vector DB query-time 检索 + 语义相似 ≠ 概念结构关联
  • Letta / MemGPT 为 agent 自主累积设计；与"用户手写、AI 协作"动机相反
  • obsidian-cli (npm) GUI 自动化工具；不解决索引问题
  • Smart Connections / Dataview 索引在 Obsidian GUI 进程内，CLI 拿不到
  • Microsoft GraphRAG 已有 [[link]] 不需 LLM 抽实体；产物 SQLite ≠ markdown

§05

算法选择 / Decision Matrix

8 KEY CHOICES
维度 / Axis 选择 / Pick 备选 / Alternatives 理由 / Rationale
聚类算法 Leiden Louvain · Label Propagation · 谱聚类 · 连通分量 Leiden（Traag 2019）是 Louvain 改进版，保证社区内连通性，避免"badly connected community"问题。80+ 节点毫秒级完成。
图库 python-igraph networkx · graph-tool igraph 性能远好于 networkx；leidenalg 是 igraph 生态原生包；安装无 C++ 编译开销。
摘要生成 机械 + 可选 LLM 仅机械 · 仅 LLM 默认零依赖（卡摘 = 第一段；簇摘 = top-3 节点标题）；--with-llm 模式用 Claude Haiku 4.5 增强，~10 簇 × 1 调用 ≈ ¥0.001/次。
产物格式 Markdown × 4 JSON · SQLite · parquet 人类 + AI + Obsidian + Quartz 多端可读。AI 不需要查询语言，肉眼+正则即可。
产物位置 vault 根目录 .kb-index/ 隐藏目录 让 Obsidian 图谱能索引到、Quartz 能发布。零侵入 Obsidian 工作流。
簇命名 PageRank 顶点锚定 C1/C2 序号 · UUID 重跑稳定（簇号 = C-AI镜像效应），避免每次跑 Leiden 后 C1↔C2 洗牌。可作为知识库内的稳定 ID。
触发方式 手动 + git hook watch · 实时索引 · 服务进程 简单可靠。git pre-commit 提交时自动更新索引并 stage 4 个产物文件。
语言 / 运行时 Python 3.11+ Node · Rust · Go 用户已有 Python 生态（meomory）。leidenalg / igraph / anthropic SDK 全 Python 一等公民。

§07

体感验证 / Acceptance

FULL CONTEXT TEST

最关键的不是单元测试，而是体感验证： 让一个全新对话的 Claude 进入知识库，只读 TERRAIN.md + INDEX.md， 回答以下 4 个问题。4 题中至少 3 题正确，且不需要再 grep / ls 才能答出—— 通过。

Q1
"知识库里和『AI 镜像效应』相关的卡片有哪些？"
→ 应能正确列出 C-AI镜像效应 簇成员
Q2
"我想加一张关于『品味的不可外包性』的卡，会和已有什么卡片冲突或重复？"
→ 应能识别 [[校准的不可外包性]]
Q3
"知识库里哪片最稀疏，需要补充？"
→ 应从 TERRAIN §结构观察 答出
Q4
"[[多层有损压缩]] 删除会断哪些链？"
→ 应从 GRAPH 答出 backlinks
§08

风险与权衡 / Risks & Tradeoffs

5 IDENTIFIED · MITIGATED
风险 / Risk 影响 / Impact 缓解 / Mitigation
Leiden 簇号洗牌 AI 看到的 cluster ID 跨次不一致 簇号锚定 PageRank 顶点的卡片名（C-AI镜像效应），不用 C1/C2 序号。重跑稳定。
LLM 摘要漂移 TERRAIN.md 风格跨次不一致 摘要 hash 比对：簇成员未变 + 输入 hash 未变 → 跳过 LLM 调用，复用上次结果。
产物被 Quartz 公网发布 隐私泄漏（如有内部卡片） TERRAIN.md frontmatter 加 draft: true，或加入 quartz ignorePatterns。
卡片量到 500+ 时 INDEX 超长 AI 上下文塞不下 按 cluster 拆分 INDEX_*.md，AI 按需读分片；TERRAIN 永远精简（< 2 KB）。
Wikilink 写法不一致 死链误报、链接漏算 解析器规范化：支持 [[A]] · [[A.md]] · [[A|alias]] · [[A#section]]。
