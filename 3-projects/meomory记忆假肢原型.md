# meomory 记忆假肢原型

**状态**：进化搜索 v4→v6 完成，发现适应度幻觉和共享矩阵天花板，搭子集成完成
**来源**：[[从记忆理论到状态恢复：meomory原型的设计基础]]

## 目标

给 LLM agent 补上**被动激活**能力——记忆自动浮现，不需要主动搜索。本质上不是记忆系统，是 [[记忆假肢]] / 状态恢复系统。

## 核心架构

### 记忆分层

| 层 | 定位 | 机制 | 状态 |
|----|------|------|------|
| L0 | 永远在上下文 | 自动注入 | 已有 |
| L1 | [[前意识激活层]] | DGD [[关联记忆]]（能学能忘） | ✅ 已实现 |
| L2 | 兜底搜索 | cosine 向量相似度 | ✅ 已实现 |
| L3 | 冷存储 | 原始 session 存档 | ✅ 已实现 |

### 消息流

```
用户消息 → [前意识激活层: DGD 匹配记忆 → 注入] → LLM 回复
                                                    ↓
                                          [观察者: LLM 判断引用了哪些]
                                                    ↓
                                          [DGD 更新 M: 强化被引用的关联]
```

### 三个关键组件

1. **DGD 关联记忆**：从 Hope/Nested Learning（NeurIPS 2025）拆出的权重矩阵，O(1) 查询，在线学习，自然遗忘。拆出来做独立外挂记忆模块是原创用法。
2. **LLM 判断者反馈**：观察 agent 回复，判断哪些注入的记忆被实际引用，产生学习信号。无需人工标注。
3. **并行执行**：每轮所有查询并发，14 题 10 秒完成。

## 实验结果（2026-03-15/16）

### 大规模实验：3 数据集 × 7 方法 = 21 次实验

| | BigBang (14题) | Friends (12题) | TheOffice (8题) |
|--|---------------|----------------|-----------------|
| BM25 | 35.7% | 33.3% | 12.5% |
| Cosine | 57.1% | 25.0% | 25.0% |
| DGD+GT (oracle) | **78.6%** | **41.7%** | **50.0%** |
| DGD+Judge (9b) | **78.6%** | 25.0% | **50.0%** |
| DGD+Judge (DeepSeek) | 71.4% | 25.0% | **50.0%** |
| DGD+CMS (9b) | 42.9% | 33.3% | **50.0%** |

### 关键发现

1. **2/3 数据集上 DGD 追平 GT**：BigBang +21.5pp, TheOffice +25pp，全自动无需人工
2. **Friends 上 DGD 完全无效**：GT 也只到 41.7%，说明数据集本身语义鸿沟太大，M 矩阵的线性变换不足以弥补
3. **CMS 在短期 benchmark 上反而有害**：280 次查询不足以让三层分化，高频层的快速遗忘冲掉了有效关联
4. **9B 小模型 ≈ 大模型**：qwen3.5:9b 效果与 DeepSeek 一致甚至更好
5. **DGD 不是万能的**：方向可行但不是所有场景都适用

### DGD 工作原理

M 是一个 256×256 的权重矩阵（65K 参数的单层线性网络）。它不替代向量库，而是套在向量库前面——查询向量先经过 M 变换（旋转、拉伸），再和向量库比较。M 通过反馈学会了"这类查询应该往哪个方向偏"。来源：Hope 架构（Nested Learning, NeurIPS 2025）的权重更新规则，拆出来做独立外挂记忆模块是原创用法。

### 反馈机制演进

```
v0: 人工标注 → 准确但不可扩展
```

## 进化搜索（2026-03-17 ~ 03-19）

### v4/v5：train=test 评测（有缺陷）

用 FunSearch 群岛模型 + 多 LLM（9b/DeepSeek/GPT-5.4）进化 DGD update rule。

| 结果 | 数值 | 真实性 |
|------|:---:|--------|
| 500 题最高 | 87.6% | 子集过拟合 |
| 全量 1976 题 | 60.1% | train=test，不泛化 |
| LongMemEval | 95.5% | train=test |
| **冷启动 test** | **0.9%** | **真实——比 cosine 22% 还差** |

进化出了 Adam + Momentum + 双通道 + BatchNorm——擅长记忆，不擅长泛化。

### v6：在线流式评测（修正后）

改为"先测再学" + 打乱题目顺序 + 混合噪声。5 种架构 seed（DGD/CMS/gen059/gen057/blank）。

| 结果 | 数值 | 真实性 |
|------|:---:|--------|
| cosine baseline | 22.4% | 不学习 |
| **v6 最强（gen107）** | **26.0%** | **真实在线泛化** |
| 冷启动 test (1 轮) | 17.5% | 比 v4 好但仍低于 cosine |

进化方向完全改变：经验回放 + 行归一化 + 残差连接 + 学习率衰减。

### 核心发现

1. **[[适应度幻觉]]**——fitness 函数错了，进化方向就错。87% 是幻觉，26% 是真实
2. **[[共享矩阵干扰天花板]]**——256×256 共享矩阵在线学习的天花板约 26%（打乱模式）
3. **[[研究者过拟合]]**——我自己也被高分锚定，在实际应用到搭子时才发现问题
4. 进化在正确的选择压力下独立发现了经验回放（DQN 2015）、残差连接（ResNet 2015）等已知技术
5. DGD 的真实定位："重复模式加速器"——对反复出现的查询有效，对新查询无效

## 搭子(dazi) 集成

将 gen059 算法移植为 TypeScript，集成到搭子 AI Agent 平台的用户记忆系统。

- DGD reranker：cosine 全量排序 → DGD 重排序 → top-5
- 异步 Judge 反馈：LLM 回答后 fire-and-forget 调 Judge → DGD update

## 理论基础

- [[可行动状态]] — 记忆的终点是"现在能怎么做"

- [[多层有损压缩]] — 遗忘是代价不是故障
- [[主动遗忘]] — 检索控制，不是删除
- [[记忆假肢]] — 我们做的是假肢，不是真记忆
- [[前意识激活层]] — 被动激活，LLM 不需要决定"要不要读"

- [[Hope记忆外挂]] — DGD 零件用于在线学习的激活层
- [[记忆与图书馆]] — 向量库是图书馆，关联记忆才接近真正的记忆
