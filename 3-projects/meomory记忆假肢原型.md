# meomory 记忆假肢原型

**状态**：原型验证完成，实验证明方向可行

## 目标

给 LLM agent 补上**被动激活**能力——记忆自动浮现，不需要主动搜索。本质上不是记忆系统，是 [[记忆假肢]] / 状态恢复系统。

## 核心架构

### 记忆分层

| 层 | 定位 | 机制 | 状态 |
|----|------|------|------|
| L0 | 永远在上下文 | 自动注入 | 已有 |
| L1 | [[前意识激活层]] | DGD [[关联记忆]]（能学能忘） | ✅ 已实现 |
| L2 | 兜底搜索 | cosine 向量相似度 | ✅ 已实现 |
| L3 | 冷存储 | 原始 session 存档 | ✅ 已实现 |

### 消息流

```
用户消息 → [前意识激活层: DGD 匹配记忆 → 注入] → LLM 回复
                                                    ↓
                                          [观察者: LLM 判断引用了哪些]
                                                    ↓
                                          [DGD 更新 M: 强化被引用的关联]
```

### 三个关键组件

1. **DGD 关联记忆**：从 Hope/Nested Learning（NeurIPS 2025）拆出的权重矩阵，O(1) 查询，在线学习，自然遗忘。拆出来做独立外挂记忆模块是原创用法。
2. **LLM 判断者反馈**：观察 agent 回复，判断哪些注入的记忆被实际引用，产生学习信号。无需人工标注。
3. **并行执行**：每轮所有查询并发，14 题 10 秒完成。

## 实验结果（2026-03-15/16）

MemoryBench DialSim-bigbang，805 个片段，14 个问题，20 轮：

| 方法 | P@1 | 相比 cosine |
|------|-----|------------|
| Cosine（不学习） | 57.1% | — |
| DGD + Ground Truth | 78.6% | +21.5pp |
| **DGD + LLM Judge（全自动）** | **71.4%** | **+14.3pp** |

### 关键发现

1. **DGD 能学习**：ground truth 下 +21.5pp，学习曲线持续上升
2. **LLM 判断者 >> embedding 相似度**：反馈准确率 72% vs 50%，前者驱动稳定学习，后者震荡不收敛
3. **自动反馈闭环可行**：无人工标注，LLM 观察 agent 行为即可产生有效信号
4. **反馈机制是瓶颈**：DGD 本身没问题，反馈信号的质量决定了学习上限

### 反馈机制演进

```
v0: 人工标注 → 准确但不可扩展
v1: embedding cosine → 50% 准确率，不够（走不通）
v2: LLM 判断者 → 72% 准确率，足够驱动学习 ✓
```

## 理论基础

- [[可行动状态]] — 记忆的终点是"现在能怎么做"
- [[关联记忆]] — M(key)→value，DGD 是工程实现
- [[多层有损压缩]] — 遗忘是代价不是故障
- [[主动遗忘]] — 检索控制，不是删除
- [[记忆假肢]] — 我们做的是假肢，不是真记忆
- [[前意识激活层]] — 被动激活，LLM 不需要决定"要不要读"
- [[条件记忆]] — Engram 从工程路径独立验证了同一套架构
- [[Hope 记忆外挂]] — DGD 零件用于在线学习的激活层
- [[记忆与图书馆]] — 向量库是图书馆，关联记忆才接近真正的记忆
