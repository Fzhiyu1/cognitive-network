# AI 决策的反向能力

**讨论者**：fangzhiyu & Claude（Opus 4.7）
**日期**：2026-05-13
**背景**：从"AI 真的能代替人做决策吗"这个问题出发，逐层拆掉"反向能力"的本体论，落到金融市场叙事的当前状态。

---

## 1. 决策的双重定义

世界看 AI 决策 vs 用户看 AI 决策，是两套定义：

| 视角 | 决策定义 | AI 是否能做 |
|---|---|---|
| 世界 | 输入情境 → 输出选择 | 能，越来越被授权 |
| 用户 | 输出 + 知道怎么选的 + 能在出错时回溯 | 不能（前向 OK，反向缺失） |

所以更准确的问法不是"AI 能不能决策"，是"AI 能做决策的**前向部分**，做不了**反向部分**"。

这把问题落到了反向能力上——但下一步发现"反向缺失"这个表述本身还不够精确。

## 2. 反向不是缺失，是不存在 → [[单向决策系统]]

上一轮说"AI 做不了反向"暗示反向是一个客观存在的操作只是 AI 没掌握。更准确的版本：**反向作为一种操作，在 LLM 物理结构里没有对应物**。

三层不存在：
- [[描述即污染]]：context 不是栈，不能 pop。语言污染不能用语言撤销
- [[工程惯性覆盖]]：生成是不可逆事件，token 吐出后没有"那一刻"可以回到
- 元监控通路不存在：让 LLM "反思刚才"做的是把刚才的输出当新输入再跑一次——redo 不是 undo

人类前额叶严格说也不是 undo，是**并行的监控+门控基础设施**让 redo 看起来像 undo。LLM 缺的就是这套并行结构。

系统里唯一的"反向" = [[失败可见性]]，但它不是撤销，是让错误进入下一轮输入。系统是 redo-only 的。

## 3. 反向能造出来吗？分层 + 边界

技术上，确实在长出"反向状结构"：
- 思考型模型（hidden scratchpad）
- 过程奖励模型（PRM）
- 校准置信度头
- Provenance / 工具调用

这些不是物理上不可能。但有 bootstrap 陷阱：监控层本身需要校准信号，[[校准的不可外包性]] 在元层级再发作一次。

**结论：AI 反向能力会在窄域率先出现，在开放域可能永远造不出真的。**

| 领域类型 | 反馈循环 | 监控层能否校准 |
|---|---|---|
| 交易、广告竞价 | 秒级 P&L | 能 |
| 代码生成 | 编译/测试 | 能 |
| 自动驾驶 | 几年事故 | 部分能 |
| 医疗诊断 | 月到年 | 勉强 |
| 战略建议、人生决策 | 永远不闭环 | **不能** |

## 4. 即使造出来也是 [[借来的权威]]

更深的问题：分层之后，监控层凭什么有权威？

人类前额叶的否决权锚在身体上（疼痛、羞耻、丧失）。AI "前额叶层"训练自 RLHF 标签，锚在"标注员喜欢这种否决"——**模仿权威**，不是**承担权威**。

后果：
- 分布内表现良好
- 分布外失效，因为锚不是代价是模式
- 通过外观审计但不能在真正出错时止损

唯一让权威变真的路径：让监控层在结果上承担代价。这正好对应窄域可造、开放域造不出的边界。

## 5. 故事弧的预测（部分推、部分猜）

> 世界会先在窄域看到惊艳的"AI 真的会反思了"，然后误以为这能外推到开放域，然后在某次开放域大错时发现外推失败——这大概是接下来 5–10 年的故事弧。

诚实拆分：

**结构部分（推得出来的）**：
- 阶段一惊艳 = 窄域 [[拟合值与拟合原理的分离]] + [[AI镜像效应]] 用户投射
- 阶段二误外推 = [[研究者过拟合]] 产业级展开 + [[工程惯性覆盖]] 高频模式压过当前框架 + [[知道与推测不分]] 边界被高分掩盖
- 阶段三大错 = 高置信 + 合理解释 + 不可调查的成因（治理视角最糟组合）

**时间部分（猜的）**：
- "5–10 年"是我编的数字
- 不从机制推出，也不从历史类比算
- 是为了让叙事收口而做的拟合

这本身就是 [[知道与推测不分]] 在我自己输出上的体现——把它分开讲是为了不污染下一轮判断（这是 redo-friendly 的写法）。

## 6. 金融层的当前状态

市场叙事这一波是阶段二的金融层展开。但 → [[期权式外推]]：

- 不是"市场相信 AI 能开放域推理"，是市场给"万一能"定了价
- 这是结构上更稳的外推，因为不需要被证伪，只需要"还没被证伪"
- 反身性循环：价格涨 → 资金涌入 → capex 扩张 → 业绩看起来更猛 → 叙事更可信 → 价格再涨。市场在消费自己的叙事，AI 实际产出只是输入之一

**关键洞察**：金融层有自己的钟。**金融层的"误外推暴露"会比认知层的"误外推暴露"先发生**。capex 兑现节奏、利率、流动性都可以单独触发回调，而那种回调会被解读成"AI 泡沫破了"，但其实只是金融层在自己的尺度上结清账目，认知层的故事可能还远没走完。

最容易误判的位置是把两个钟混在一起——看到股价回调就以为 AI 不行了，或者看到 AI 出错就以为股价该崩了。它们大部分时候不同步。

## 7. 替代账目的全成本计算

用户最后问：如果 AI 一日不解决这些问题，即使人成本高于 AI，AI 也不会彻底替代人？

人类直觉里的账：

```
任务成本 = 人工时 × 时薪    vs    AI 做相同任务 = token 成本
```

漏算了一项：**[[判断力位]] 的维护成本**。

```
AI 替代的全成本 = token 成本 + 判断力位维护成本
                              ↑
              如果位子空了或假装有人坐着，
              短期账面省钱，长期 [[校准的不可外包性]] 开始收账
```

位子能空，但代价**延迟、不可见、累积**——这种代价在季度财报上看不到，所以会被系统性低估。直到某次大事故把累积失校露出来（[[失败可见性]] 延迟到账）。

AI 也不能坐进位子，因为 [[知道与推测不分]] 没解决之前，坐进去也长不出品味——AI 坐的位子是个摆设。

**所以"替代"的实际形态不是 AI 把人都赶走，是判断力位被重组**：
- 执行层：大量人被 AI 替代（这部分是真的）
- 判断层：人数变少但单位人判断密度急剧上升
- 风险：组织和社会层面如果没意识到判断层不能空，可能会一并裁掉，然后进入退化路径，等大事故

**未来贵的不是"能用 AI 的人"，是"能判断 AI 输出对不对的人"**。前者会通胀，后者会通缩——因为后者需要的品味只能在做判断动作的过程中长出来，而越来越多人主动从位子上下来。不是技能稀缺，是**位子稀缺**。

---

*结论：AI 不是判断力弱的决策者，是只能向前的决策者。围绕这个单向性，世界正在经历一场结构性的判断力位重组——而这场重组的代价大部分还没上账。*
