# 时序表征调研：从NeurIPS最佳论文到harness直觉

**讨论者**：fangzhiyu & Claude (Opus)
**日期**：2026年8月18日
**背景**：从 B 站视频《追求奖励完全错误！强化学习应该学习时序表征》（Eysenbach，NeurIPS 2025 最佳论文作者演讲）出发，调研该技术能否迁移到自有数据资产。

---

## 一、技术本体

论文主张：不学奖励，学时序表征——把状态映射为向量，使向量距离≈状态间最短路径步数。链条：对比分类器 logit → 密度比 p(s_f|s,a)/p(s_f) → 折扣占用度量（Successor Representation）→ goal-conditioned Q。**本质是对环境转移算子做非线性低秩谱分解**；1000 层网络的贡献是证明深度（配残差+LayerNorm+Swish）解锁了此前"RL 网络 2~5 层"禁忌，性能 2×~50×。

## 二、七次实验与证伪链

| # | 尝试 | 结果 | 死因 |
|---|---|---|---|
| 1 | git 仓库画结构图（7 仓） | 3/7 出图 | 图是"信息不足"的产物；armada 谱平则糊 |
| 2 | git 共改召回 | 26% vs 共现计数 27% | 有表可建时表征永远输给表 |
| 3 | git"导航" | 69% 系假象 | 图是人为构造的，git 无转移 |
| 4 | 打乱 commit 顺序对照 | 召回几乎不变，零时序版反而最高 | **commit 是集合不是轨迹**；所谓时序表征在 git 上= word2vec |
| 5 | agent 日志（工具名词袋）进度预测 | 0.367 = log(t) 基线 | 信号在内容里，粗编码丢光 |
| 6 | 迷宫放大实验（状态 49→3102） | C@C 全程 2 倍碾压神经网络 | stitching 是矩阵乘法性质，非网络专利 |
| 7 | 语义状态 + 时序对比精炼 | 0.518→0.400 负增益 | InfoNCE 目标与成败信号不重合 |

收束为 [[时序表征适用地图]]：状态可枚举→数数；覆盖率低→计数+k 跳传播；**只有状态不可枚举（连续/高维）时神经网络才必要**——它是表的替代品，不是升级品。四条成立前提：真轨迹、有目标、有控制者、状态编码够细。

## 三、关键概念转折

1. **"我们在控制什么？"** —— 论文控制机械臂；我们迄今什么都没控制。学到的 V 只是仪表不是方向盘。harness 语境下唯一真实的被控对象是**会话调度**（继续/中止/换模型/裁剪），而非 LLM 的逐步 tool call（LLM 自己选得更好）。
2. **"这是带着技术找应用"** —— 用户自我点破。见 [[带着技术找应用]]：出口 A（产品）颗粒无收，出口 B（适用地图）满载而归。
3. **每轮的失望反应本身是病灶**：简单基线赢了本该高兴（问题解决且免费），失望说明在乎的是技术出场而非问题解决。

## 四、意外的正结果

放弃时序对比、只保留"语义内容进状态"：MiniLM 编码 73880 个事件 + Ridge/Logistic 线性探针，956 会话留出验证——**前 25% 预测成败 AUC 0.832**，错误率基线 0.485。详见 [[harness直觉信号]]。

三个发现：会话命运在前 1/4 已定大半（过程奖励存在性证据）；报错数与成败无关；赢的是朴素动作不是先进方法。

## 五、遗留验证与方向

- 标签审计（"正常收尾"近似标签可能有捷径）+ 按 cwd 分组交叉验证（防记项目作弊）
- 在 dsh（自有 harness，turn/step/tool 三层干净标签）上复验
- 下游全为只读应用：止损、并行裁剪、SFT 数据筛选；17% 误判期内不给方向盘
